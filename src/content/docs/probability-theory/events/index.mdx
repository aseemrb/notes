In this section, we move from the static description of probability spaces to the dynamic behavior of random experiments. We will explore how to describe outcomes numerically using **Random Variables**, and how to analyze the relationships between different events.

## Key Topics

1.  **[Limits and Independence](limits-independence)**:
    -   What does it mean for a sequence of events to happen "infinitely often"?
    -   What does it fundamentally mean for two events or $\sigma$-fields to be "independent"?
2.  **[Random Variables](random-variables)**: How to rigorously define variables that depend on random outcomes, and when they are independent.
3.  **[Borel-Cantelli Lemmas](borel-cantelli)**: First major tools to decide if an event happens infinitely often or not.
4.  **[Kolmogorov's 0-1 Law](kolmogorovs-law)**: A surprising result showing that "tail events" (events happening in the asymptotic future) are deterministic for independent sequences.

These tools form the bedrock for proving the Laws of Large Numbers and the Central Limit Theorem.
