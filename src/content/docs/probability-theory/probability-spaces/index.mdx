A **Probability Space** is the mathematical foundation upon which all of probability theory is built. It provides a consistent framework to quantify "randomness" without falling into logical traps.

In this chapter, we will construct the triplet $(\Omega, \cF, \Pr)$ step-by-step:

1.  **[$\sigma$-Fields](sigma-fields)**: Defining "measureable" events $\cF$.
2.  **[Probability Measures](measures)**: Defining the function $\Pr$ that assigns probabilities to these events.
3.  **[Carathéodory's Extension Theorem](extension)**: A powerful tool to construct probability measures on complex spaces.
4.  **[Lebesgue Measure](lebesgue-measure)**: The canonical example of a probability measure on continuous space, derived using the extension theorem.
